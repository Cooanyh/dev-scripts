## 功能特点

### 🌍 多货币支持

支持识别和转换以下货币：

| 货币 | 符号/代码 | 示例 |
|------|----------|------|
| 美元 | `$` / `USD` | $99.99、USD 100 |
| 欧元 | `€` / `EUR` | €89.00、EUR 50 |
| 英镑 | `£` / `GBP` | £79.99、GBP 30 |
| 日元 | `¥` / `JPY` | ¥1000、JPY 500 |
| 港币 | `HK$` / `HKD` | HK$88、HKD 100 |
| 韩元 | `₩` / `KRW` | ₩10000、KRW 5000 |
| 新台币 | `NT$` / `TWD` | NT$300、TWD 500 |
| 澳元 | `A$` / `AUD` | A$50、AUD 100 |
| 加元 | `C$` / `CAD` | C$60、CAD 80 |
| 新加坡元 | `S$` / `SGD` | S$40、SGD 50 |
| 瑞士法郎 | `CHF` | CHF 100 |

### 📊 两种显示模式

**替换模式**
- 直接将外币价格替换为人民币金额
- 页面更简洁，适合只关心人民币价格的用户

**附加模式**（默认）
- 在原价格后追加人民币金额
- 保留原始价格信息，方便对比

### ⚙️ 丰富配置选项

- **白名单/黑名单模式**：控制脚本在哪些网站运行
- **汇率自动刷新**：可配置自动刷新间隔（10-1440分钟）
- **状态指示器开关**：可选择显示或隐藏右下角状态组件
- **模式切换自动刷新**：切换显示模式后自动刷新页面

### 🔧 技术特性

- **智能检测**：自动识别动态加载的内容
- **性能优化**：防抖处理，避免影响网页性能
- **多API支持**：自动切换备用汇率源
- **本地缓存**：减少网络请求，提升响应速度

## 安装使用

### 前提条件

安装浏览器扩展（任选其一）：
- [Tampermonkey](https://www.tampermonkey.net/)（推荐）
- [Violentmonkey](https://violentmonkey.github.io/)
- [Greasemonkey](https://www.greasespot.net/)

### 安装步骤

1. 安装上述浏览器扩展之一
2. 点击扩展图标，选择"添加新脚本"
3. 复制 [currency-converter.user.js](./currency-converter.user.js) 的全部内容
4. 粘贴并保存
5. 访问任意包含外币价格的网页即可自动转换

### 快速操作

- **打开设置**：点击浏览器扩展图标 → 外币转换助手设置
- **显示/隐藏状态指示器**：扩展菜单中可切换

## 配置说明

### 基础设置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用货币转换 | 是否启用脚本功能 | 启用 |
| 显示模式 | 替换模式/附加模式 | 附加模式 |
| 显示状态指示器 | 右下角状态组件 | 隐藏 |

### 高级设置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 切换模式后自动刷新 | 切换显示模式后自动刷新页面 | 启用 |
| 自动刷新汇率 | 定时自动更新汇率数据 | 启用 |
| 刷新间隔 | 汇率刷新间隔（分钟） | 120分钟 |

### 网站过滤

| 模式 | 说明 |
|------|------|
| 所有网站运行 | 在所有网站启用脚本 |
| 仅白名单网站运行 | 只在指定网站运行 |
| 黑名单网站不运行 | 在指定网站禁用脚本 |

白名单/黑名单支持通配符，例如：
- `amazon.com` - 精确匹配
- `*.amazon.com` - 匹配所有子域名
- `*.com` - 匹配所有 .com 网站

## 常见问题

**Q: 为什么有些价格没有被转换？**

A: 可能原因：
1. 价格格式不符合识别规则
2. 该网站被加入了黑名单
3. 汇率数据未加载成功

**Q: 汇率多久更新一次？**

A: 默认每2小时自动更新，可在设置中调整（10-1440分钟）。

**Q: 支持哪些浏览器？**

A: 支持 Chrome、Firefox、Edge、Safari 等主流浏览器。

**Q: 会影响网页性能吗？**

A: 脚本经过优化，使用防抖处理和智能检测，对网页性能影响极小。

## v0.3.0 更新说明

- 重构动态页面的价格扫描策略，改为优先基于可见元素的 `innerText` 识别用户实际看到的外币价格

- 修复重复注入人民币价格导致页面卡死的问题，提升动态页面下的稳定性
